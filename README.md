# Hospital Management System 

A clean and simple console-based application built using **Java** to manage basic hospital administrative tasks.
---

## Project Overview
This project was developed as an individual project to demonstrate core **Object-Oriented Programming (OOP)** concepts, data management using collections, and clean code structuring in Java.
---

## Features
- **Doctor Management:** Add new doctors and view registered doctor details.
- **Patient Management:** Add new patients and view registered patient details.
- **Patient Search:** Select/Search a patient by their unique Patient ID.
- **Interactive Menu:** Console menu interface with an option to exit the system smoothly.
---

## Technologies Used
- **Language:** Java
- **Core Concepts:** OOP , ArrayLists, Scanner
